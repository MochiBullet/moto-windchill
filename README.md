# 🏍️ バイク体感温度計算機

オートバイ走行時の体感温度をリアルタイムに計算するWebアプリです。

## 入力項目

| 項目 | 範囲 |
|------|------|
| 気温 | -20 〜 45 ℃ |
| 走行速度 | 0 〜 180 km/h |
| 湿度 | 0 〜 100 % |
| 風速（向かい風） | 0 〜 20 m/s |

## 計算モデル

- **Wind Chill Index**（Environment Canada / NWS）に基づく風速冷却モデル
- 走行速度 + 向かい風 = 合成風速として計算
- 高温・高湿度時はヒートインデックスを考慮

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバー不要。
